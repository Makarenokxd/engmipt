# Пайка: RC-цепь

Плата AUX (R2 + C1 10 мкФ, кнопка S1 разряжает C1) подключена разъёмом PWR/GND/SIG к блоку AUX платы get-adc.
Напряжение на конденсаторе (SIG) меряет 10-битный АЦП MCP3021 (I2C, адрес 0x4D).

## Запуск на Raspberry Pi
1. `raspi-gpio set 2 a0` и `raspi-gpio set 3 a0` (после каждой перезагрузки).
2. Перемычку **ADC Input** поставить на вход AUX/SIG.
3. `python3 rc_measure.py` — 15 с записи; во время записи отпускай/зажимай S1 (зарядка/разрядка).
4. `python3 rc_plot.py` — график U(t) в rc_plot.png и оценка tau = R*C.

Проверка: tau ≈ R·C. Например, R = 10 кОм, C = 10 мкФ → tau = 0,1 с.
